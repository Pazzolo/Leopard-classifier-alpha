# Rúbrica — Criterios

> Fuente: [Plantilla.md §4](../Plantilla.md)

Cada ítem se evalúa de forma independiente con uno de estos criterios:

```
Nota del ítem = Puntuación Máxima × Porcentaje Asignado / 100
```

| Implementación | Defensa | % |
| --- | --- | --- |
| Completa | Excelente | 100 |
| Completa | Regular | 75 |
| Parcial | Excelente | 50 |
| Parcial | Regular | 25 |
| Completa | Insuficiente | 25 |
| Parcial | Insuficiente | 0 |
| Inexistente | — | 0 |

- **Excelente:** los estudiantes pueden defender, entender y justificar completamente sus decisiones de diseño, criterios de implementación y lo que afirman en el texto.
- **Regular:** pueden hacerlo parcialmente.
- **Insuficiente:** no pueden hacerlo.

## Implicaciones

- Una implementación completa con una defensa insuficiente vale solo 25 %. **Todos** los integrantes deben entender cada decisión, no solo quien la programó.
- Cada ítem debe dejar escrito en la notebook **por qué** se tomó cada decisión (métrica, k, rango de hiperparámetros, test estadístico, etc.).
