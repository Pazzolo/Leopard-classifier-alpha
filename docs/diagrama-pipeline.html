Qué significa cada paso

1Datos

El pipeline sirve para texto, series de tiempo, tabular o imágenes. Nuestro caso: imágenes, 850 fotos del dataset v2 (color, 5 especies).

2Feature extraction

Convierte cada foto en números. a) Clásica: píxeles + PCA, HoG/SIFT. b) Transfer learning: una red preentrenada (la pizarra sugiere CLIP; el Plan A usa ResNet50).

3Embedding

La salida del extractor: un vector por foto (2048 números con ResNet50). Desde aquí el problema es tabular.

4Feature selection *

El asterisco indica que es para datos tabulares. Con imágenes y transfer learning la rúbrica permite omitirlo.

5Modelos

SVM vs. Random Forest. Se buscan los hiperparámetros con repeated k-fold CV (curva de optimización) y se predice la especie (target).
